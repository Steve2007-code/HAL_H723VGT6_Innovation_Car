# HAL_H723VGT6_Innovation_Car

2027 年工创智能搬运小车 · STM32H723VGT6 HAL 工程

用达妙 4310P ×4 的轮速反馈做里程计、DM-IMU-L1 的陀螺 yaw 做航向锁定，
在 48×48（50 mm/格）地图上跑 8 邻域 A*，靠麦轮全向平移走完「启停区 → 扫码区 → 夹取区 → 物料区」。

**当前版本：v0.3.0（2026-11-16）· 底盘运动学 + 航向锁定 + A* 寻路**

| MCU | STM32H723VGT6，HSE 24 MHz → SYSCLK 480 MHz / AHB 240 MHz |
| 底盘电机 | 达妙 DM-J4310P ×4，速度模式，PMAX 300 / VMAX 30，减速比 10 |

| IMU | 达妙 DM-IMU-L1，FDCAN3，CANID 0x06，回传 0x16 |
| 底盘 | 麦轮 X 型布置，轮径 97 mm，轴距 180 mm，轮距 235 mm，车体 275×275 mm |
| 灯 | WS2812，SPI6 + BDMA（缓冲区在 D3 SRAM4） |
| 调试串口 | USART1 @ 115200 |
| 时基 | TIM4 1 ms 中断 |

电机与车轮对应关系：

| CANID | 位置 | 轮型 | 数据块 |
|---|---|---|---|
| 0x01 | 左前 | A（左旋） | `DM_Motor_4310P_Next_StructData` |
| 0x02 | 右前 | B（右旋） | `DM_Motor_4310P_StructData` |
| 0x03 | 左后 | B（右旋） | `DM_Motor_4310_StructData` |
| 0x04 | 右后 | A（左旋） | `DM_Motor_4310_Next_StructData` |

> 右前、右后两轮安装镜像，方向系数默认 `{+1, -1, +1, -1}`（实车标定）。

控制链路：

```
TIM4 1ms 中断
 └─ 每 5ms (200Hz)
      Attitude_Update()   yaw 积分，每 10ms 发一次 IMU 请求（欧拉角 + 角速度）
      Odom_Update()       四轮正解 → 世界系积分
      Nav_Update()        位置环 + 航向环
      Chassis_Update()    斜坡 → 逆解 → 等比限幅 → 4 帧 CAN
 主循环
      Debug_Task()        串口命令行 + 10Hz CSV 遥测
      A* 规划（事件触发，结果原子提交给中断）
```

CAN 负载：4 帧 / 5 ms = 800 fps @1 Mbps ≈ 11%。

## 关键设计决策

### 1. 障碍「间隙判据」而不是整格膨胀

车体 275 mm，中部通道 450 mm，单边余量只有 87.5 mm。
整格膨胀 2 格会让通道「变成 250 mm < 车宽」直接无解；膨胀 1 格又不够（100 mm < 137.5 mm 半宽）。

改为按真实间隙判据：**路径中心到实体障碍格的距离场（切比雪夫）≥ 4 格 = 152.5 mm** 才可规划。
物料 / 夹取 / 扫码区只自身阻挡、**不参与膨胀**，否则车永远贴不到区域边缘。

> 实测膨胀 0~4 格全有解，但纵向 400 mm 通道只剩 `rows 23–24` 两行，单边余量 62.5 mm。

### 2. 航向锁定 + 全向平移，而非车头跟着路径转

275 mm 方车在 450 mm 通道里原地转向，半对角扫掠 194.5 mm，只剩 30 mm 单边余量 —— 转不开。
策略定为：**上电那一瞬的车头朝向就是全程锁定朝向**，靠 vx/vy 分解平移走完折线，全程不原地转向。
IMU 的职责变成「把 yaw 锁死，不让打滑把车身带歪」。

### 3. 速度指令是减速器输出端 rad/s

换算只有一步：`ω_wheel = v_wheel / 0.0485`，10:1 减速比不进公式，少一个误差源。

### 4. 方向系数同时作用于下发与反馈

系数同时乘在「下发的轮速」和「反馈的轮速」上，翻转后里程计方向自动一致，不需要额外补偿。

### 5. 控制全在 1 ms 中断里分频，A* 在主循环

A* 约 1~3 ms，在主循环跑，结果**原子提交**给中断（`__disable_irq` 只包住拷贝），不打断 200 Hz 节拍。

## 坐标系与约定

| 项 | 约定 |
|---|---|
| 世界系 | x 向右（地图 col 方向），y 向上（row 递减），原点 = 地图左下角，单位 mm |
| 车体系 | x 向前，y 向左，ωz 俯视逆时针为正 |
| 格子 ↔ 坐标 | 格心 = `((col+0.5)*50, (47-row+0.5)*50)` |
| 上电朝向 | 车头朝世界 **+x**，yaw 置 0 |

摆放要求：车放启停区中心、车头朝地图向右、目视偏角 < 10°；
`Attitude_Calibrate(400)` 那 400 ms 车必须完全静止。

## 串口协议（USART1 / 115200）

运动类命令必须包在包头包尾之间，防止总线噪声拼成命令让车自走：

```
<<命令 参数>>
```

| 命令 | 说明 |
|---|---|
| `<<v 0.15 0 0>>` | 手动车体速度（m/s, m/s, rad/s），带 800 ms 看门狗 |
| `<<g 23 46>>` | A* 规划到格子 row=23 col=46 |
| `<<p 2325 1225>>` | A* 规划到世界坐标 mm |
| `<<z 5 0>>` | 规划到功能区：2 启停 / 3 物料 / 4 夹取 / 5 扫码 |
| `<<s 0 3>>` | 单轮点动（0 左前 / 1 右前 / 2 左后 / 3 右后） |
| `<<d 1 -1>>` | 轮方向标定 |
| `<<r 45 45>>` | 重置位姿到格心（yaw 归零） |
| `<<k 3.5 0.3>>` | 位置环 kp / kd |
| `<<h 4 0.2>>` | 航向环 kp / kd |
| `<<c 0.95>>` | 里程计比例标定 |
| `<<w 0>>` | 手动看门狗开关 |

只读 / 急停命令不用包：`?` `o` `i` `m` `t` `x` `e`

`z` 的第二个参数是「同类里第几个」：`2` 的 `0`=下方 `1`=上方；`3` 的 `0`=左 `1`=底；`4`/`5` 只有 1 个恒填 `0`。

停靠格（按「离区域质心最近的可规划格」自动算）：

| 区域 | 停靠格 (row, col) |
|---|---|
| 扫码 5 | (23, 46) |
| 夹取 4 | (2, 23) |
| 物料 3 · 左 | (23, 3) |
| 物料 3 · 底 | (44, 23) |
| 启停 2 · 下 | (45, 45) |

遥测：`$Tick,row,col,x_mm,y_mm,yaw_deg,vx,vy,wz,state,wp_index`

## 主要参数

| 宏 | 值 | 含义 |
|---|---|---|
| `CH_WHEEL_R` | 0.0485 | 麦轮半径 m |
| `CH_WHEEL_BASE` / `CH_WHEEL_TRACK` | 0.180 / 0.235 | 轴距 / 轮距 m |
| `CH_K` | 0.2075 | (L+W)/2 |
| `CH_RAD_USE` | 12.0 | 轮角速度上限 rad/s ≈ 0.58 m/s |
| `CH_VXY_MAX` / `CH_WZ_MAX` | 0.60 / 2.50 | 车体速度 / 角速度上限 |
| `CH_ACC_V` / `CH_ACC_W` | 1.2 / 8.0 | 加速度斜坡 |
| `NAV_CLEAR_CELLS` | 4 | 路径中心离障碍最少格数 = 152.5 mm |
| `NAV_ARRIVE_MM` / `NAV_FINAL_MM` | 14 / 8 | 中间点 / 终点到达判据 |
| `NAV_MANUAL_TIMEOUT_MS` | 800 | 手动速度看门狗 |
| `ATT_LPF` | 0.50 | 角速度低通 |

三条任务路径长度 ≈ **1121 / 1878 / 1786 mm**（@0.5 m/s 约 2.2 / 3.8 / 3.6 s）。
