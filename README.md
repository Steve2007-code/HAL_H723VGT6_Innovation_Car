# 2027 Innovation Car · 智能搬运小车

2027 年工创智能搬运小车 —— **双板架构**：H723 底盘 + F103 直角坐标机械臂。

底盘用达妙 4310P ×4 的轮速反馈做里程计、DM-IMU-L1 的陀螺 yaw 做车头跟随，在 48×48（50 mm/格）地图上跑 8 邻域 A*，车头对准行进方向、拐点处原地转向，走完「启停区 → 扫码区 → 夹取区 → 物料区」。
机械臂由 F103 控制，顶视相机给出目标像素偏差：**yaw 轴（达妙 4340P）追 x 误差、A 轴（步进）追 y 误差**，两轴解耦。两板通过 UART 双向通信，F103 把 yaw 目标角交给 H723 代发 CAN。

**当前版本：v0.4.0（2026-11-20）· 双机通信 + yaw/A 轴视觉闭环 + 底盘导航**

## 硬件平台

### H723 底盘

| 项 | 配置 |
|---|---|
| MCU | STM32H723VGT6，HSE 24 MHz → SYSCLK 480 MHz / AHB 240 MHz |
| 底盘电机 | 达妙 DM-J4310P ×4，速度模式，PMAX 300 / VMAX 30，减速比 10 |
| 电机 CAN | FDCAN1 @ 1 Mbps，指令 `0x200+ID`，回传 `0x11~0x14` |
| IMU | 达妙 DM-IMU-L1，FDCAN3，CANID 0x06，回传 0x16 |
| yaw 轴 | 达妙 DM4340P，位置速度模式，CANID 0x05，指令 `0x105`，回传 0x15 |
| 底盘 | 麦轮 X 型布置，轮径 97 mm，轴距 180 mm，轮距 235 mm，车体 275×275 mm |
| 灯 | WS2812，SPI6 + BDMA（缓冲区在 D3 SRAM4） |
| 调试串口 | USART1 @ 115200（PA9/PA10） |
| 板间串口 | **UART7 @ 115200**（PE7 = RX / PE8 = TX，AF7） |
| 时基 | TIM4 1 ms 中断 |

电机与车轮对应：

| CANID | 位置 | 轮型 | 数据块 |
|---|---|---|---|
| 0x01 | 左前 | A（左旋） | `DM_Motor_4310P_Next_StructData` |
| 0x02 | 右前 | B（右旋） | `DM_Motor_4310P_StructData` |
| 0x03 | 左后 | B（右旋） | `DM_Motor_4310_StructData` |
| 0x04 | 右后 | A（左旋） | `DM_Motor_4310_Next_StructData` |

> 右前、右后两轮安装镜像，方向系数默认 `{+1, -1, +1, -1}`（实车标定）。

### F103 机械臂

| 项 | 配置 |
|---|---|
| MCU | STM32F103C8T6，CMSIS 裸机（无 HAL / 无 CubeMX） |
| 摄像头串口 | USART1 @ 115200，帧 `<<X,dx,Y,dy>>`，**30 fps** |

## 双机通信

物理层：**3.3 V TTL 直连、必须共地、TX/RX 交叉**

```
F103 PA2 (TX) ──→ H723 PE7 (RX)
H723 PE8 (TX) ──→ F103 PA3 (RX)
GND ─────────────── GND
```

帧集（`<<...>>` 成帧，帧内不含换行，无校验和）：

| 方向 | 帧 | 频率 | 含义 |
|---|---|---|---|
| F103 → H723 | `<<Y,pos_mrad,vel_mradps>>` | 100 Hz | yaw 目标角 / 限速，单位 0.001 rad、0.001 rad/s |
| F103 → H723 | `<<E,1>>` | 100 ms 补发至收到 `K,2` | 请求使能 4340（幂等） |
| H723 → F103 | `<<A,pos,vel,err>>` | 20 Hz | 4340 实际角度 / 速度 / 错误字节，只存不解释 |
| H723 → F103 | `<<K,code>>` | 事件触发 | 1 上电就绪 / 2 已使能 / 3 非法帧 / 4 限幅 / 5 断链 |

**握手与自愈**：H723 上电 `K,1`（不参与链路活性）→ F103 持续补发 `E,1` → H723 使能 4340 并回 `K,2` → F103 置 `s_yaw_ack` 停止补发。H723 若中途重启，F103 收到新的 `K,1` 会**清 `s_yaw_ack`** 重新补发，yaw 自动复活。

**看门狗**：H723 侧 400 ms 收不到 `Y` 就停发 `0x105` 并保持位置；F103 侧 1 s 收不到 `A`/`K` 就停发 `Y`。

**限幅**（两侧一致）：目标角 `-2269 ~ 2269`（-130° ~ +130°），速度 `±6000`（±6 rad/s）。

## 关键设计决策

### 1. 障碍「间隙判据」而不是整格膨胀

车体 275 mm，中部通道 450 mm，单边余量只有 87.5 mm。
整格膨胀 2 格会让通道「变成 250 mm < 车宽」直接无解；膨胀 1 格又不够。
改为按真实间隙判据：**路径中心到实体障碍格的切比雪夫距离 ≥ 4 格 = 152.5 mm** 才可规划。
物料 / 夹取 / 扫码区只自身阻挡、**不参与膨胀**，否则车永远贴不到区域边缘。

### 2. 车头跟随转向：拐点处先停、原地转、再前进

每段路径锁定一个段航向，车头对准段方向前进；航向偏差 > 25°（`NAV_TURN_GATE`）先停车原地转向。
A* 的斜线段会拉出「车头一上来就拧几度」的问题，因此航点还要过一道**正交化**（`s_ortho()`）：把斜段折成 L 形，拐角优先延续当前车头方向，并合并共线航点 → 所有航段平行于地图轴、拐点全 90°。

### 3. 非运行态一律硬停

`Nav_Update()` 在 `NAV_IDLE / NAV_DONE / NAV_FAIL` 时直接 `Chassis_Hold(); return;`，**不做航向保持**。
否则 `s_yaw_t` 会保留上一段航向，配合 IMU 零偏漂移持续输出 `wz` → 车走完原地自转、急停停不住、不发命令也自己动。

### 4. yaw 闭环用 x 像素误差，不用极角

早期用 `atan2(dx, -dy)` 极角，但本机相机是 **y 向上为正、x 向右为负**（与标准图像坐标双轴翻转）。目标在画面上方时 `-dy` 为负，phi 落在 ±180° 附近并在 ±π 处跳变 → 剧烈抖动。
改为**直接用 `dx`**：yaw 只负责让 x 误差归零，A 轴负责 dy，两轴彻底解耦。

### 5. yaw 防超调：超前量限幅 + 软着陆

**超调量 ≈ 转速 × 延迟**（5 rad/s × 100 ms ≈ 500 mrad = 28.6°），与 KP/KD 无关——这是位置伺服绕不过的物理规律。

- **超前量限幅**：目标角不允许领先 4340 实际角度超过 `YAW_LEAD_MAX`（来自 A 帧的 `pos`），积分饱和被物理杜绝；断链时自动失效。
- **软着陆**：误差 < `YAW_SLOW_PX` 时，领头量按 `|误差| / YAW_SLOW_PX` 线性收紧 → 大误差全速、到位前自然减速。

### 6. A 轴为什么不用同一套

A 轴是**速度伺服**（直接给 pps），没有「目标位置」这个中间量，也没有积分器。
`v = KP × dy` 本身就是误差越小速度越慢的比例控制，天然具备软着陆特性。它的过冲若出现，来源是减速斜坡而不是积分饱和。

### 7. 控制全在 1 ms 中断里分频，A* 在主循环

A* 约 1~3 ms，在主循环跑，结果**原子提交**给中断（`__disable_irq` 只包住拷贝），不打断 200 Hz 节拍。

### 8. 视觉帧门控

`YawTrack_Update()` 虽以 100 Hz 被调用，但相机只有 30 fps。若同一帧被重复累加 2~3 次，yaw 目标会冲过头 → 反向修正 → 来回震荡。因此用 `g_last_frame_ms` 时间戳判断**只在真正拿到新帧时累加一次**。

## 坐标系与约定

| 项 | 约定 |
|---|---|
| 世界系 | x 向右（地图 col 方向），y 向上（row 递减），原点 = 地图左下角，单位 mm |
| 车体系 | x 向前，y 向左，ωz 俯视逆时针为正 |
| 格子 ↔ 坐标 | 格心 = `((col+0.5)*50, (47-row+0.5)*50)` |
| 上电朝向 | 车头朝世界 **+y**（地图上方），yaw 置 90°（`NAV_YAW_INIT`） |

**相机像素坐标系（本机）**：右上方 `x−/y+`、左上方 `x+/y+`、右下方 `x−/y−`、左下方 `x+/y−` —— 即 **y 向上为正、x 向右为负**。

摆放要求：车放启停区中心、车头朝地图上方、目视偏角 < 10°；`Attitude_Calibrate(400)` 那 400 ms 车必须完全静止。

## 串口协议（H723 调试口 USART1 / 115200）

运动类命令必须包在包头包尾之间，防止总线噪声拼成命令让车自走：`<<命令 参数>>`

| 命令 | 说明 |
|---|---|
| `<<v 0.15 0 0>>` | 手动车体速度（m/s, m/s, rad/s），带 800 ms 看门狗 |
| `<<g 23 46>>` | A* 规划到格子 row=23 col=46 |
| `<<p 2325 1225>>` | A* 规划到世界坐标 mm |
| `<<z 5 0>>` | 规划到功能区：2 启停 / 3 物料 / 4 夹取 / 5 扫码 |
| `<<s 0 3>>` | 单轮点动（0 左前 / 1 右前 / 2 左后 / 3 右后） |
| `<<d 1 -1>>` | 轮方向标定 |
| `<<r 45 45>>` | 重置位姿到格心（yaw 归零） |
| `<<k 3.5 0.3>>` | 位置环 kp / kd |
| `<<h 4 0.2>>` | 航向环 kp / kd |
| `<<c 0.95>>` | 里程计比例标定 |
| `<<w 0>>` | 手动看门狗开关 |
| `<<f 90>>` | 到点后原地对准指定朝向（90=朝上，`999`=取消） |

只读 / 急停命令不用包：`?` `o` `i` `m` `t` `x` `e`

停靠格（按「离区域质心最近的可规划格」自动算）：

| 区域 | 停靠格 (row, col) |
|---|---|
| 扫码 5 | (23, 46) |
| 夹取 4 | (2, 23) |
| 物料 3 · 左 | (23, 3) |
| 物料 3 · 底 | (44, 23) |
| 启停 2 · 下 | (45, 45) |

遥测：`$Tick,row,col,x_mm,y_mm,yaw_deg,vx,vy,wz,state,wp_index`
