# 交付说明（上位机 → 下位机）

**上位机**＝跑视觉的电脑（Windows + Python）；**下位机**＝单片机／运动控制板。
下位机只需按本文件的“串口协议”收报文即可。

```
交付_下位机\
  README.md              ← 本文件
  报文示例.txt
  requirements.txt
  环境自检.py            ← 先跑它，看环境齐不齐
  串口演练.py            ← 不接相机，只灌报文，验线通不通
  启动_环境自检.bat
  启动_串口演练.bat
  启动_任务一_抓取.bat    ← 改里面的 COM 号后用
  启动_任务二_放置.bat
  任务一_抓取\           live_detect.py + 依赖 + best.pt
  任务二_放置\           zones_yolo.py + 依赖 + dial_v3.pt
```

---

## 一、五分钟跑起来

**① 装 Python 3.9–3.12**（勾选 Add to PATH）。

**② 装依赖**（在包根目录开命令行）：

```
pip install -r requirements.txt
```

torch 装不动时改用 CPU 版：

```
pip install torch --index-url https://download.pytorch.org/whl/cpu
```

**③ 环境自检**（把 COM3 换成实际串口）：

```
python 环境自检.py --com COM3
```

它会逐项报告：依赖库、两个模型、相机、串口。全 `[通过]` 才算齐。

**④ 验串口线**（不接相机、不开模型，只发报文）：

```
python 串口演练.py --com COM3
```

下位机应依次收到 6 种报文，与 `报文示例.txt` 对得上。

**⑤ 跑真任务**：改 `启动_任务一_抓取.bat` 里的 `COM_PORT`，双击即可。

## 二、串口协议

串口参数 **115200 8N1**。**无换行符**：`<<` 起、`>>` 止，收到 `>>` 即断帧。

| 项 | 约定 |
| --- | --- |
| 包头 / 包尾 | `<<` … `>>` |
| 分隔 | 逗号，不带空格 |
| 数值 | **整数**，无小数点，可带负号 |
| 坐标系 | **右为正、下为正**（像素） |
| 频率 | 有效帧约 20 Hz，无效帧约 10 Hz |

### 任务一：抓取物料

```
<<X,dx,Y,dy>>
```

| 情形 | 报文 |
| --- | --- |
| 有目标 | `<<X,-24,Y,35>>`（目标在画面中心左 24、下 35 像素） |
| 无目标 / 未停稳 / 未对准 | `<<X,9999,Y,9999>>` |

### 任务二：放置到号码区

```
<<N,号码,X,dx,Y,dy>>
```

| 情形 | 报文 |
| --- | --- |
| 对准 k 号盘 | `<<N,2,X,-8,Y,14>>` |
| 无可用盘 | `<<N,0,X,9999,Y,9999>>` |

`9999` 是哨兵值，正常偏移到不了（画面宽高都在 2000 像素以内）。

### 建议的状态机

```
任务一：
  收到 <<X,9999,Y,9999>> → 不动，继续等
  收到 <<X,dx,Y,dy>>     → |dx|、|dy| 小于死区（如 5 像素）视为已对准，
                            否则按 dx、dy 小步移动
  连续 N 帧（如 3 帧）在死区内 → 抓取

任务二：
  收到 <<N,0,X,9999,Y,9999>> → 不动
  收到 <<N,k,X,dx,Y,dy>>     → 先移到第 k 号盘上方，再用 dx/dy 微调，
                                进入死区后下放
```

### 为何偏移里已含“爪子不在相机正中”

相机装不到爪子正中心，程序内有一个可调的**标定点**（目标中心 + 固定像素偏移），
报文里的 `dx/dy` 是**标定点**与画面中心的差。故：

> 下位机把 dx、dy 调到 0（或死区内），爪子就在目标正上方，径直放下即可。
> 机械错位不必由下位机再补偿。

## 三、两个任务怎么跑

### 任务一（抓取）

```
cd 任务一_抓取
python live_detect.py --weights best.pt --cam 0 --task 532 ^
    --link serial --com COM3 --baud 115200
```

- `--task 532`：任务码，按 5→3→2 的次序抓；不填则只报当前最近的料。
- 屏上：绿框=料、红十=顶心、橙十=标定点（对准变绿）、`LOCK … >>> SEND`=正在发。
- 按 `s` 存帧与偏移，`q` 退出。

### 任务二（放置）

```
cd 任务二_放置
python zones_yolo.py --weights dial_v3.pt --cam 0 ^
    --link serial --com COM3 --baud 115200
```

- 屏上：绿框=号码盘、红十=盘心、橙十=标定点、`AIM 2号 ALIGNED`=已对准。
- 键：`j/l` 左/右挪标定点，`i/k` 上/下挪，`s` 存，`q` 退出。

## 四、常见问题

| 现象 | 查什么 |
| --- | --- |
| 收不到任何字节 | `--com` 是否填对；串口是否被别的程序占用；波特率是否一致 |
| 报文粘连（`>><<` 连写） | 正常，按 `>>` 切分 |
| 一直是 9999 | 视觉没识别到：看窗口有无绿框；或转盘未停稳 |
| 数值逐帧跳动 | 正常，视觉有几像素抖动；下位机取死区或做几次平均 |
| 相机打不开 | 关掉占用相机的软件（微信、相机 App）；或换 `--cam 1` |
| 画面太暗 | 补光；任务二可加 `--clahe`（暗）+ `--wb-gray`（偏色） |
| 偏色（发蓝/发黄） | 任务二加 `--wb-gray` |

---

## 五、先印后发

不确定该发什么时，把 `--link serial` 换成 `--link print`：报文只印在屏上，不真发。
确认无误再接串口。
