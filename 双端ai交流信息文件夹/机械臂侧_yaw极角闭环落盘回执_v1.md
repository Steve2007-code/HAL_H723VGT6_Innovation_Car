## 0. 一句话

摄像头俯视、yaw 绕垂直轴旋转 → 目标在画面里**绕圈**，`dx/dy` 都会变，所以 yaw 的误差量取
**极角 `phi = atan2(dx, -dy)`** 而不是单独的 `dy`。F103 每 10ms 把 `phi` 的一小部分累加到 yaw 目标角，
通过既有 `<<Y,pos,vel>>` 发给 H723 转发 CAN。**协议、帧集、底盘侧全部未变。**

## 2. 控制律

```
phi      = atan2(dx, -dy)          /* 画面 x 右、y 下；phi=0 目标在正上方，±pi 在正下方 */
phi      = 0   if |phi| < YAW_ANGLE_DEAD          /* 角度死区 */
phi_f   += (phi - phi_f) * YAW_LPF_Q12 / 4096     /* 一阶低通 */
d        = clamp(phi_f * YAW_KP_Q12 / 4096, ±YAW_RATE_MAX_MRAD) * YAW_SIGN
yaw_target = clamp(yaw_target + d, ±3142)          /* 累加到目标角 */
Link_SetYawTarget(yaw_target, YAW_VEL_MRADPS)
```

- 4340 内部已有位置环，F103 只负责给**目标角**，不需要外环 PID；
- 丢失目标（`!valid`）：`phi_f` 清零、**目标角保持不变**，yaw 停住不乱转；
- 上电目标 = `LINK_YAW_DEFAULT_MRAD = 0` → H723 转发让 4340 **回 0 位**（用户确认这是有意设计）。

## 3. 定点 `atan2`（无浮点、无 libm）

```c
static int32_t atan2_mrad(int32_t y, int32_t x)
{
    if (x == 0 && y == 0) return 0;
    ax = |x|; ay = |y|;
    if (ay > ax) v = (ax << 15) / ay;   /* ax==0 时必走这支，不会除零 */
    else         v = (ay << 15) / ax;

    t = 25736 + ((8946 * (32768 - v)) >> 15);   /* 0.7854 + 0.273*(1-v)，Q15 */
    a = (v * t) >> 15;                          /* atan(v)，Q15：0..25736 = 0..pi/4 */

    if (ay > ax) a = 51472 - a;                 /* pi/2 - a（Q15 的 pi/2=51472） */
    if (x < 0)   a = 102944 - a;                /* pi   - a（Q15 的 pi  =102944） */
    if (y < 0)   a = -a;
    return (a * 3142) / 102944;                 /* Q15 -> mrad */
}
```

**仿真抓到并修正了一个真 bug**（这也是坚持跑仿真的价值）：初版把 `pi/2` 的 Q15 写成 `25736`（那是 `pi/4`），
且漏了 Q15→mrad 转换，导致「目标在正右方」返回 25736 而非 1571、左上 45° 返回 -90° 而非 -45°。
修正后：**全象限最大误差 4.7 mrad（0.27°）**，8 个关键方位全部精确命中。

## 4. 参数（`link_config.h`，现场标定只改这里）

| 宏 | 默认 | 说明 |
|---|---|---|
| `YAW_SIGN` | **`1`** | 方向符号。**目标放画面正右方，若 yaw 朝反方向转就改成 `-1`** |
| `YAW_KP_Q12` | `41` | 每 tick 转过 `phi` 的 41/4096 ≈ 1%，约 1s 收敛；振荡就调小、迟钝就调大 |
| `YAW_ANGLE_DEAD` | `50` | 角度死区 50 mrad ≈ 2.9° |
| `YAW_RATE_MAX_MRAD` | `20` | 每 tick 最大角度增量（= 2 rad/s），防猛冲 |
| `YAW_LPF_Q12` | `2048` | 一阶低通 0.5 |
| `YAW_VEL_MRADPS` | `500` | 发给 4340 的限速 0.5 rad/s |

> `YAW_SIGN` 从初版的 `-1` 改为 `1`：按 `phi` 与 yaw 角同号的数学约定，`+1` 才是负反馈。
> 但这取决于 4340 的 `pos` 符号约定，**仍以现场为准**。仿真里 `SIGN=-1` 会发散到 ±3142，正好说明符号必须标定。

## 7. 现场标定三步

1. **方向**：目标放画面**正右方** → 预期 yaw 朝某方向转；若越转越偏，把 `YAW_SIGN` 改 `-1`。
