# 达妙电机 ID 配置操作指南（OpenArm 双臂）

> 目标：把左右臂共 16 个达妙电机的 CAN ID 配置为 OpenArm 标准（每臂 J1~J7 + 夹爪 = 0x01~0x08 / 0x11~0x18），为后续联调做准备。
> 依据：达妙 DMTool 官方说明书（2026.03 V1.0）+ OpenArm 官方 Step1 Motor ID 文档。

---

## 0. 核心概念（先搞懂，避免配反）

达妙电机参数里有两个 ID，和 OpenArm 代码里的叫法**恰好相反**，这是最容易出错的地方：

| OpenArm 文档叫法 | 含义 | 达妙电机参数名 | 双臂标准值 |
|------------------|------|----------------|-----------|
| **Sender CAN ID**（发送ID） | 主站发送命令用的 ID = **电机接收** | **ESC_ID（接收ID）** | 0x01 ~ 0x08 |
| **Receiver (Master) ID**（接收ID） | 主站接收反馈用的 ID = **电机发送** | **MST_ID（反馈ID）** | 0x11 ~ 0x18 |

> ⚠️ 在 DMTool 参数界面里：**ESC_ID 填 0x01~0x08，MST_ID 填 0x11~0x18**。填反会导致后面 CAN 通讯不上（电机不响应）。

### 双臂 ID 分配表（两只手臂用相同 ID，靠不同 CAN 总线区分）

| 关节 | 电机型号 | ESC_ID 接收ID | MST_ID 反馈ID |
|------|----------|---------------|---------------|
| J1 | DM-J8009P | 0x01 | 0x11 |
| J2 | DM-J8009P | 0x02 | 0x12 |
| J3 | DM-J4340 | 0x03 | 0x13 |
| J4 | DM-J4340 | 0x04 | 0x14 |
| J5 | DM-J4310 | 0x05 | 0x15 |
| J6 | DM-J4310 | 0x06 | 0x16 |
| J7 | DM-J4310 | 0x07 | 0x17 |
| 夹爪 J8 | DM-J4310 | 0x08 | 0x18 |

> 右臂、左臂各配一套相同 ID（共 16 台电机）；同一手臂内 ID 不能重复。建议每配好一台就贴标签（如"右J3"）。

## 1. 需要准备的硬件

| 项目 | 说明 |
|------|------|
| **USB-TTL 3.3V 串口模块**（CH340 / CP2102 等） | 连接电机调试串口改 ID（达妙说明书推荐方式） |
| 或 **达妙 USB-CAN 调试器** | OpenArm 文档方式（老版本工具 v1.6.8.8 可用） |
| GH1.25 3-pin 调试线 / 杜邦线 | 接电机调试口（靠近 LED 的 3-pin 口） |
| 24V 电源 | 给电机供电（配置时电流约 0.3A/台即可） |
| Windows 电脑 | 运行 DMTool |

> 串口模块如 CH340 需要装驱动（Windows 一般自动安装；不行就去 WCH 官网下载 CH341SER 驱动）。连接：**模块 TX → 电机 RX，模块 RX → 电机 TX，GND 共地**，波特率 **921600**。若线序不确定，先看电机附带说明书或达妙 GitHub（github.com/dmBots/DAMIAO-Motor）。

## 3. 操作步骤（串口方式，一次配置一台电机）

> **每次只给一台电机上电接线**，配完一台再换下一台，避免搞混。

### Step 1：接线
1. 给电机接 24V 电源（电机 LED 应点亮）。
2. USB-TTL 串口模块插入电脑，用线连接电机 GH1.25 3-pin 调试口（RX↔TX 交叉 + 共地）。
3. 打开"设备管理器 → 端口(COM 和 LPT)"，确认出现 COM 口（记下端口号，如 COM3）。

### Step 2：打开串口
1. 运行 DMTool。
2. 界面选择刚识别的 **COM 口**，波特率选 **921600**。
3. 点击"打开"（Open）。若下拉列表里没有，刷新或重插模块。

### Step 3：读参数
1. 切到 **"参数设置"** 标签页。
2. 点击 **"读参数"**，稍等片刻，界面会显示电机当前全部参数。
3. 确认读到的参数正常（有电机型号相关参数出现），说明通讯 OK。

### Step 4：修改 ID
1. 找到 **MST_ID（反馈ID）** 字段：按上表填入该电机的反馈值（如 J1 填 `17`，即 0x11）。
2. 找到 **ESC_ID（接收ID）** 字段：按上表填入该电机的接收值（如 J1 填 `1`，即 0x01）。
3. 其余参数**不要动**（尤其极对数、减速比、编码器相关）。

> 注：界面中 ID 可能以十进制显示（0x11 = 17，0x18 = 24），注意换算；部分版本界面直接用十六进制。

### Step 5：写参数（保存）
1. 确认电机处于**失能（不使能）**状态。
2. 点击 **"写参数"**。写入成功后驱动器会自动重启（无需断电）。
3. 等 1~2 秒。

### Step 6：验证
1. 再次点击 **"读参数"**，确认 MST_ID / ESC_ID 已变成你填的值。
2. 给电机贴上标签（如"右J1"），断电，换下一台电机重复 Step 1~6。

### Step 7：全部配完后
- 16 台电机（右臂 8 + 左臂 8）都配好后，**断电、按 CAN 总线装回双臂**。
- 后续可在 Ubuntu 上用 `motor-check` 或 candump 做最终通讯验证（见《双臂上电运行手册》第 4~5 节）。

## 4. 备选：用达妙 USB-CAN 调试器 + v1.6.8.8（OpenArm 文档方式）

如果你手上有达妙 USB-CAN 调试器（OpenArm 文档要求的设备），可用 v1.6.8.8：

1. 打开 v1.6.8.8（界面左下有中/英文切换）。
2. 选择调试器对应的端口（通常是列表最后一个）。
3. 点击 **ReadParam（读参数）** 读取电机参数。
4. 在 ID 栏填入上表的 Sender / Master ID（此版本界面用 OpenArm 的叫法：Sender=0x01~0x08，Master=0x11~0x18）。
5. 点击 **WriteParam（写参数）** 保存。

> ⚠️ 新版 DMTool（2.1.x）在 **CAN 模式下默认不提供 CAN ID 修改**（说明书明确建议用串口改 ID，防止误改）。若你的电机只有 CAN 线接入（无调试串口），需要先接 USB-TTL 串口完成 ID 配置。

## 5. 常见问题排查

| 现象 | 处理方法 |
|------|----------|
| 打开串口失败 / 找不到 COM 口 | 换 USB 口；安装 CH340/CP2102 驱动；重插模块；设备管理器里看端口号 |
| 读参数无响应 | 波特率是否 921600；RX/TX 是否交叉；是否共地；电机是否已供电；换线试 |
| 写参数后电机状态异常 | 写入时电机必须失能；写完后会自动重启属正常现象 |
| SmartScreen/Defender 拦截 exe | "更多信息→仍要运行"；或保护历史记录里"允许" |
| 两台电机 ID 配重了 | 同一条总线上 ID 必须唯一；重读参数逐个核对，重配重复的那台 |
| 不确定当前电机是什么 ID | 单台电机单独接线读参数即可看到当前值，再改 |

## 6. 配好后的快速验证（可选，推荐）

在 Windows 上用 DMTool 的 **调试界面** 验证单台电机：
1. 接好电源 + CAN 线（用 USB-CAN 调试器或后面 Linux 的适配器）。
2. DMTool 调试界面输入该电机的接收 ID（ESC_ID）。
3. 点 **Enter（使能）**，再给一个小的力矩/位置值，电机应转动。
4. 测试完设 0 并失能。

> 这一步确认电机 ID 正确、电机能响应命令，再去上 Linux 联调双臂。
